# Лабораторна робота №7: RMI (Розподілені обчислення)

## Опис проєкту
Проєкт реалізує розподілену клієнт-серверну систему за технологією Remote Method Invocation. 

## Реалізований функціонал
- **Code-on-Demand:** Сервер (обчислювач) динамічно завантажує та виконує завдання (`Task`), які надсилає клієнт.
- **Точні обчислення:** Реалізовано обчислення константи `e` (основа натурального логарифма) з точністю 50 знаків за допомогою ряду Тейлора та класу `BigDecimal`.
- **Автоматизація розгортання:** Налаштовані пакетні файли (`.bat`) для компіляції, запуску RMI-реєстру, сервера та клієнта.
