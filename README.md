# Лабораторна робота №8: RMI Conference Registration

## Опис проєкту
Комплексний розподілений застосунок для віддаленої реєстрації учасників наукової конференції, що поєднує RMI, Swing GUI та роботу з XML.

## Реалізований функціонал
- **RMI Сервер:** Програмне створення реєстру. Зберігання бази учасників (JavaBeans).
- **RMI Клієнт:** Графічний інтерфейс користувача для віддаленого виклику методів реєстрації та отримання інформації.
- **DOM XML Інтеграція:** Серверна можливість експорту бази учасників у файл XML за допомогою DOM-парсера та імпорту існуючої бази з диска в оперативну пам'ять.
