# Лабораторна робота №4,5: Java Net Programming (TCP Sockets)

## Опис проєкту
Проєкт реалізує розподілений клієнт-серверний додаток, що взаємодіє через мережу з використанням надійного протоколу TCP.

## Реалізований функціонал
- **TCP Сервер:** Багатопотоковий сервер (`ServerSocket`), який приймає підключення від кількох клієнтів одночасно та обробляє їхні запити в окремих потоках (`ClientHandler`).
- **TCP Клієнт:** Додаток (`Socket`), що встановлює з'єднання з сервером для передачі серіалізованих об'єктів-запитів.
- **Бізнес-логіка:** Моделювання передачі завдань на обчислення або системи обслуговування карток з гарантованою доставкою повідомлень та обробкою мережевих виключень.
