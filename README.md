# Лабораторна робота №1: Java Reflection API

## Опис проєкту
Проєкт демонструє використання механізмів Java Reflection API для динамічного аналізу та маніпуляції об'єктами під час виконання програми.

## Реалізований функціонал
- **Аналіз структури класу:** Отримання інформації про пакети, модифікатори, поля, конструктори та методи за іменем класу.
- **Інспекція об'єктів:** Динамічний аналіз стану об'єкта (значення полів) та його реального типу.
- **Динамічний виклик методів:** Виклик методів об'єкта за їхнім іменем у вигляді рядка з обробкою власного виключення `FunctionNotFoundException`.
- **Робота з масивами:** Динамічне створення та зміна розмірів масивів і матриць примітивних і посилальних типів.
- **Dynamic Proxy:** Використання динамічних проксі-об'єктів для профілювання (вимірювання часу виконання) та трасування методів.
