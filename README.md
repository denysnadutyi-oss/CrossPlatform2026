# Лабораторна робота №5,6: Java Net Programming (UDP Sockets)

## Опис проєкту
Проєкт демонструє мережеву взаємодію за допомогою датаграмного протоколу UDP, який забезпечує швидку, але не гарантовану доставку повідомлень.

## Реалізований функціонал
- **UDP Ехо-сервер та клієнт:** Асинхронний обмін даними за допомогою `DatagramSocket` та `DatagramPacket`.
- **Реєстрація вузлів:** Сервер реєстрації IP-адрес для подальшої P2P взаємодії.
- **Multicast Конференція:** Текстовий чат для групи користувачів з використанням `MulticastSocket`, що дозволяє розсилати повідомлення всім підписникам групи (IP: 224.0.0.1) з підтримкою графічного інтерфейсу (Swing).
