# Лабораторна робота №3: Java & XML (Аналіз датасетів)

## Опис проєкту
Проєкт призначений для синтаксичного аналізу, фільтрації та валідації великих наборів відкритих даних у форматі XML (датасет популярних імен Нью-Йорка).

## Реалізований функціонал
- **SAX Аналіз:** Швидке потокове зчитування великого XML-файлу без завантаження в пам'ять для вилучення унікальних тегів та категорій.
- **Валідація XSD:** Програмна перевірка коректності структури XML-документа за допомогою власноруч створеної схеми `schema.xsd`.
- **DOM Маніпуляція:** Фільтрація даних за етнічною групою, сортування за рейтингом та створення нового, оптимізованого XML-файлу за допомогою Document Object Model (DOM).

## Запуск
Для коректної роботи покладіть вхідний файл `Popular_Baby_Names_NY.xml` та `schema.xsd` у кореневу директорію проєкту перед виконанням класів.
