# Лабораторна робота №2: Java Serialization

## Опис проєкту
Проєкт моделює роботу інформаційної системи (наприклад, облік бібліотеки або навчального процесу) з використанням механізмів збереження та відновлення стану об'єктів.

## Реалізований функціонал
Реалізовано три різні стратегії серіалізації:
1. **Стандартна серіалізація:** Використання інтерфейсу `java.io.Serializable` для всіх об'єктів системи.
2. **Керована серіалізація:** Використання `Serializable` з модифікатором `transient` для окремих полів та перевизначенням методів `writeObject()` і `readObject()`.
3. **Externalizable:** Повний ручний контроль над процесом збереження та відновлення через реалізацію інтерфейсу `java.io.Externalizable` (методи `writeExternal()` та `readExternal()`).
